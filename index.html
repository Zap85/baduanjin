预备式

并步站立 → 虚领顶劲 → 沉肩垂肘 → 松腕舒指 → 开步同宽 → 屈膝抱球

要点：腋下虚空两臂掤，拇指放平膝不超，心静体松预备好。

1 两手托天理三焦

腹前叉掌 → 中线缓托 → 过胸翻掌 → 举顶抬头 → 收颌撑掌 → 十指分落 → 捧回腹前

要点：耸肩是大忌，眼随手走不乱瞟，先抬后收上下拔，脚趾抓地像树牢。

2 左右开弓似射雕

开步搭腕 → 沉肘换型 → 马步蹲 → 八字推掌龙爪拉 → 对直如弓 → 目视食指 → 收脚还原

要点：膝盖不超脚尖线，身体朝前头可转，劲从脊背发出来，不用蛮力要自然。

3 调理脾胃须单举

一手托天 → 一手按胯 → 掌根对拉 → 身正稍停 → 原路返回

要点：身子莫歪要端平，两掌同起又同落，掌根发力才到位，脾胃调和身体轻。

4 五劳七伤往后瞧

挺膝伸直 → 臂外旋 → 头转后 → 展肩扩胸稍停 → 转正落臂按胯

要点：只转脑袋不转身，旋臂充分慢柔转，莫要猛甩伤颈椎，五劳七伤自然消。

5 摇头摆尾去心火

马步扶膝 → 尾闾领 → 腰胯画圆 → 头随摆 → 回正坐稳

要点：尾椎先动头后跟，脑袋不主动去甩，圆活连贯像蛇行，心火下降神安宁。

6 两手攀足固肾腰

两臂上举 → 反穿腋 → 贴背摩运至臀 → 上体前俯摸脚面 → 手臂领起

要点：膝盖挺直不弯曲，起身手臂带身体，攀足摸脚肾腰固，动作到位才有益。

7 攒拳怒目增气力

马步握固 → 收腰间 → 贴肋冲拳渐收紧 → 怒目盯拳 → 旋腕握回

要点：出拳莫耸肩和肘，前臂擦肋往前走，目光如电要有神，气力自增精神抖。

8 背后七颠百病消

头顶虚领 → 提脚跟 → 抓地舒展 → 稍停 → 轻落震地 → 周身松

要点：提踵中正莫后仰，起落舒缓不慌张，轻颠七次病邪走，浑身轻松精神爽。
